# Endless Elite

Gemeinsames, modular aufgebautes Quellrepository für die von Agegee und Hermes entwickelten Hytale-Mods.

> **Status:** Repository-Baseline vor der Mod-Zusammenführung. Die Integration erfolgt auf einem separaten Feature-Branch. Bestehende Originalprojekte bleiben unverändert als Sicherheitskopien erhalten.

## Sicherheitsregeln

- Keine Serverzugangsdaten, Tokens, Passwörter oder lokalen Authentifizierungsdateien.
- Keine Hytale-/Drittanbieter-JARs oder unnötigen Buildausgaben.
- Kein Force-Push und keine umgeschriebene Historie.
- Runtime-, Client- und Multiplayer-PASS werden getrennt von Build-/Unit-Test-PASS dokumentiert.

Weitere Modul-, Build- und Installationsdokumentation folgt mit der verifizierten Integration.
